# Hi there 👋

## Рад тебя видеть на моём профиле в GitHub!

Я **Frontend-разработчик с коммерческим опытом более 5 лет**. Специализируюсь на разработке сложных корпоративных интерфейсов, CRM-систем и внутренних платформ.

Проектирую архитектуру frontend-приложений, разрабатываю переиспользуемые компоненты и UI-kit, оптимизирую производительность и покрываю критические пользовательские сценарии тестами.

## Основные направления работы

- **Frontend-архитектура** — проектирование масштабируемых и поддерживаемых приложений на React и Next.js.
- **Корпоративные приложения** — разработка CRM-систем, аналитических панелей и внутренних платформ.
- **UI-kit и дизайн-системы** — создание переиспользуемых компонентов и развитие компонентной архитектуры.
- **Оптимизация производительности** — повышение скорости работы приложений, оптимизация рендеринга и загрузки данных.
- **Тестирование** — автоматизация проверки критических пользовательских сценариев.
- **Интеграция с Backend** — работа с REST API, Node.js, Express, PostgreSQL и архитектурой BFF.
